# NASA Project Portal

The NASA Project Portal showcases the details, models, and documentation for my NASA sponsored engineering capstone project. 

- 3D models were designed w/ Solidworks and convert to stls and sliced in OrcaSlicer for 3d printed manufactured prototype. The models were then converted to GLB files for interactive viewing below.
      - **note:** the GLB models are simplified prototype meshes. 

- Please checkout for a comprehensive look at my design groups project page: [Space Elevator Anchor](https://psyche.ssl.berkeley.edu/get-involved/capstone-projects/capstone-projects-iridium-class/sample-return-from-hypothesized-surfaces-osu-b/)

- If you are interested check out all other the Psyche projects: [Psyche Capstone Projects](https://psyche.ssl.berkeley.edu/get-involved/capstone-projects/)

## Site Description

This page provides an interactive overview of the NASA project, including its objectives, design process, technical documentation, and 3D models. Users can explore the project, view engineering drawings, and interact with 3D models directly in the browser.

---

## What to expect

- **Documentation:**  
  Downloadable PDFs provide in-depth technical reports, design notes, and citations.

- **3D Model Viewer:**  
  Users can interact with 3D prototye models using the integrated viewer (powered by three.js).  
  - Rotate, zoom, and pan models for detailed inspection.
  - Models are loaded from the `assets/models/nasa-project/` directory.
  - Double Clicking on Models will expand a larger inteactive viewing pane w/ discriptions.

- **Image Gallery:**  
  Browse project images, diagrams, and screenshots.

---

## Operation

1. **Interact with 3D models using the embedded viewer.**
2. **Browse documentation.**
3. **Download technical reports and supporting documents as needed.**
4. **Explore images and diagrams for additional context.**

---

## Limitations

- 3D model interaction may be limited on mobile devices.
- Only supported file formats (GLB, GLTF, PDF, PNG, JPG, MP4 and more) are viewable.
- Some documents may require a PDF viewer for full access.
